# Facade Studio — AI image prompts

Every card, door and result in Facade Studio v3 shows a photo from `img/studio/`. Until a photo exists, the card shows its file name and a **Copy ChatGPT prompt** button.

**How to use**
1. Copy the prompt below into ChatGPT (or any image model) and generate at the size shown.
2. Save the image with the exact file name shown, as a **.jpg**, into the `img/studio/` folder next to `Facade Studio v3.dc.html`.
3. Reload the studio. The image appears automatically.

Generate `sample-building` first, because the four result designs are edits of that photo.
